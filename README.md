    8. **Сервисы и утилиты**:
        - `CategoryService` - работа с API категорий доходов и расходов (полный CRUD) ✅
        - `OperationService` - работа с API операций (транзакций) ✅:
            - получение списка `/operations` и `/operations` с фильтрами (`period`, `dateFrom`, `dateTo`)
            - получение операции по `id` `/operations/:id`
            - создание операции `POST /operations`
            - обновление операции `PUT /operations/:id`
            - удаление операции `DELETE /operations/:id`
        - `BalanceService` - работа с API баланса пользователя ✅:
            - `getBalance()` - получение текущего баланса `GET /balance`
            - `setBalance(value)` - обновление баланса `PUT /balance` с проверкой корректности ответа
        - `HttpUtils` - обёртка над `fetch` с токеном и обработкой ошибок ✅
        - `AuthUtils` - управление токенами и авторизацией (сохранение/чтение, логаут) ✅
        - `UIUtils` - отрисовка сообщений и визуальные уведомления (`showMessage`) ✅
        - `balance-ui` - утилиты UI для работы с балансом ✅:
            - отображение текущего баланса по атрибуту `data-balance`
            - периодический опрос сервера (поллинг) и автообновление значения
            - модальное окно для редактирования баланса (валидация, отправка на сервер, анимация «успешно обновлено»)
        - `StorageUtils` - нормализация и очистка некорректных данных в `localStorage` ✅:
            - `normalizeLocalStorage(keys)` удаляет «битые» значения (`null`, `undefined`, пустые строки, некорректный JSON в `userInfo`)
